# UX Profile

All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom — "Scoreboard, sharpened" (Brad chose this 2026-11-14)
- **Notes:** A stadium scoreboard at night, built with discipline. Dark-first (light is the alternate). Near-black page,
  blue = you / action, green = win / live, red = loss, amber = heads-up; each player keeps a fixed colour. Tall condensed
  numbers are the identity; they carry every score, record, title, section header and label.
  - **Type sizes (px):** 12 meta · 14 secondary · 16 body · 19 · 23 · 28 headings · 40 · 48 · 58 display numbers. Nothing
    under 12. Rows and table cells are 14 or 16.
  - **Weights:** 400 / 500 / 600 only. Size carries emphasis, not weight.
  - **Faces:** IBM Plex Sans for text; IBM Plex Sans Condensed 600 for numbers, titles, section headers and the one
    uppercase label style.
  - **Spacing (px):** 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64.
  - **Radius (px):** 6 tags and chips · 10 controls · 16 cards and sheets · pill.
  - **Control heights (px):** 32 compact (44 hit area) · 44 default · 52 primary.
  - **Depth:** L0 page → L1 card / list (1px border; faint top edge light in dark, soft shadow in light) → L2 hover /
    raised → L3 sheets and menus. Lists and tables always have a frame and hairline rows.
  - **Accent:** blue only on actions, active navigation, links, focus and "you". Never a large fill.
  - **Motion:** 120 / 200 / 320ms, one easing; nothing decorative; one reduced-motion rule.

## Banned anti-aesthetics

- Multi-hue or rainbow gradients; glow stacks; hard drop shadows.
- Blur / glass panels (`backdrop-filter`).
- Emoji or text glyphs used as icons (🔒 ✓ ▲ ▼ ‹ ›).
- Illustration people or mascots in empty states.
- Decorative pills around static text; decorative icons inside inputs.
- Font weights above 600; text under 12px; a new font size, gap or radius outside the lists above.
- The team-colour stripe on more than one edge of a row.

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** text never wears a player or team colour; win / loss text uses the `--win` / `--loss` tokens, which
  differ per theme to stay at 4.5:1.
- **Touch / focus:** 44px minimum hit area (compact 32px controls extend it invisibly); 2px accent focus ring, 2px offset.

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain words a friend would use in the group chat. Records as `19-11`, money as `$200` / `−$287`.

## Icon library

- **Library:** Project SVG
- **Package / path:** `src/components/icons.tsx`
- **Notes:** 24×24, stroke 1.8, round caps and joins, `currentColor`. Add to this file; do not import an icon package.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns`; layout / chrome → `viewports`; forms → `forms`; overlays →
   `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the project SVG icons. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
